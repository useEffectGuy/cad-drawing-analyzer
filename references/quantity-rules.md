# 工程量计算口径

## 一、面积计算

### 建筑面积（GB/T 50353-2013）
- **计算全面积**：结构层高 ≥ 2.20m 的楼层；有顶盖的架空层；门斗；有柱雨篷
- **计算 1/2 面积**：结构层高 < 2.20m 的楼层；无柱雨篷；有顶盖无围护结构的车棚/货棚
- **不计算面积**：露台、露天游泳池、花架；建筑物内操作平台/上料平台；勒脚、附墙柱、垛、台阶
- **阳台**：在主体结构内的阳台按全面积；主体结构外的阳台按 1/2 面积

### 图纸面积提取规则
| 图元类型 | 面积计算方式 |
|---|---|
| 闭合 LWPOLYLINE | `e.area()` 取绝对值 |
| HATCH | `e.area()` 取绝对值 |
| CIRCLE | π × r² |
| 闭合 SPLINE | 近似（顶点多边形面积） |

### 面积单位换算
- DXF 图纸默认单位为 mm，面积单位为 mm²
- 换算为 m²：÷ 1,000,000

## 二、长度计算

### 线长提取规则
| 图元类型 | 长度计算方式 |
|---|---|
| LINE | 两端点欧氏距离 |
| LWPOLYLINE | `e.length()`（含弧段） |
| ARC | 半径 × 圆心角(弧度) |
| CIRCLE | 2π × 半径（周长） |
| SPLINE | `e.length()` |
| ELLIPSE | `e.length()` |

### 长度单位换算
- DXF 默认 mm，换算为 m：÷ 1000

### 管线长度统计口径
- 按图层统计总长度（如给水管层、排水管层）
- 不扣除管件、阀门所占长度
- 管道支架、吊架不另计长度

## 三、计数计算

### 构件计数规则
- **INSERT（块参照）**：数量 = 块参照实例数
- **带属性块**：优先从 ATTRIB 提取型号规格，按规格分组计数
- **无属性块**：按块名分组计数
- **注意**：嵌套块（块内 INSERT）不重复计数，只计外层

### 门窗计数
- 门：按 M0921、M1021 等型号分组计数
- 窗：按 C1515、C1818 等型号分组计数
- 单位：樘

### 设备计数
- 灯具、插座、开关、配电箱、洁具等
- 优先从块属性提取型号，无型号时按块名
- 单位：个/套/盏

## 四、扣减规则

### 面积扣减
- 墙体面积扣除门窗洞口
- 楼地面面积扣除凸出地面的构筑物、设备基础
- 墙面抹灰扣除门窗洞口和 >0.3㎡ 孔洞

### 长度扣减
- 管道长度不扣除阀门、管件长度
- 电缆长度需加预留长度（配电箱预留、电缆头预留）

### 计数扣减
- 同型号门窗合并计数
- 相同设备按型号归并

## 五、单位汇总

| 计量对象 | 单位 | 换算 |
|---|---|---|
| 建筑面积 | m² | mm² ÷ 1e6 |
| 楼地面/墙面/天棚 | m² | 同上 |
| 门窗 | 樘 | 计数 |
| 管线 | m | mm ÷ 1000 |
| 电缆 | m | 同上 |
| 设备/构件 | 个/套/盏 | 计数 |
| 混凝土 | m³ | 需体积计算 |
| 模板 | m² | 接触面积 |
| 钢筋 | t | 长度×线密度÷1000 |
