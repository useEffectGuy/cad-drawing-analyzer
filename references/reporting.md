# 输出报告与 Excel 模板结构说明

## 一、Excel 汇总表结构

### Sheet 列表
1. **总汇总**（首页）
2. **图纸目录**
3. **{专业}工程量**（每个专业一个 sheet）
4. **管线长度**（如有）
5. **面积统计**（如有）

### 总汇总 Sheet 结构
```
┌─────────────────────────────────────────────────────┐
│              工程量汇总统计表（合并居中）              │
├─────────────────────────────────────────────────────┤
│ 一、图纸概况                                         │
│   图纸总数    XX 张                                   │
│   涉及专业    建筑、结构、给排水、电气...              │
│     建筑      X 张                                    │
│     结构      X 张                                    │
│                                                     │
│ 二、工程量汇总                                       │
│   专业    构件类型数  构件总数  管线图层数  面积图层数 │
│   建筑      XX        XX        XX        XX          │
│   结构      XX        XX        XX        XX          │
└─────────────────────────────────────────────────────┘
```

### 分专业工程量 Sheet 表头
| 序号 | 构件名称 | 规格 | 数量 | 单位 | 所在图层 |
|---|---|---|---|---|---|

### 管线长度 Sheet 表头
| 序号 | 图层 | 长度(m) | 单位 |
|---|---|---|---|

### 面积统计 Sheet 表头
| 序号 | 图层 | 面积(m²) | 单位 |
|---|---|---|---|

## 二、样式规范

### 字体
- 标题：微软雅黑 16pt 加粗，深蓝 #1F4E79
- 表头：微软雅黑 11pt 加粗，白色
- 正文：微软雅黑 10pt

### 填充
- 表头：深蓝 #1F4E79
- 隔行：浅灰 #F2F2F2（可选）
- 标题行背景：白色

### 边框
- 全表细边框 #BFBFBF

### 对齐
- 表头：居中
- 正文：垂直居中，文字左对齐，数字右对齐

### 列宽
- 自动适配内容，最小 8，最大 40

## 三、Markdown 分析报告结构

```
# 图纸分析报告

**生成时间**：YYYY-MM-DD HH:MM:SS
**划分标准**：GB 50300-2013

## 一、图纸概况
- 图纸总数、目录来源、涉及专业分布

## 二、图纸目录
| 序号 | 图号 | 图名 | 专业 | 规格 | 备注 |

## 三、分专业工程量
- 构件类型数、总数、线长图层数、面积图层数
### 构件明细（前 20 条）
| 构件名称 | 数量 | 单位 | 规格 |

## 四、分部分项划分（GB 50300）
### {分部名称}
- **{子分部}**
  - {分项}：N 项

## 五、结论与建议
- 总结性描述
- 异常提示（目录外文件等）
```

## 四、中间产物 JSON 结构

### catalog.json
```json
{
  "generated_at": "...",
  "source": "...",
  "total_sheets": N,
  "items": [{"序号","图号","图名","专业","规格","备注","置信度"}],
  "discipline_stats": {"建筑": N, ...},
  "out_of_catalog_files": []
}
```

### quantities.json
```json
{
  "file": "...",
  "block_table": [{"block_name","quantity","unit","layers","specs"}],
  "length_table": [{"layer","total_length_mm","total_length_m","unit"}],
  "area_table": [{"layer","total_area_mm2","total_area_m2","unit"}],
  "summary": {"block_types","block_total","length_layers","area_layers"}
}
```

### wbs.json
```json
{
  "standard": "GB 50300-2013",
  "generated_at": "...",
  "divisions": {
    "{分部}": {
      "{子分部}": {
        "{分项}": [{"名称","数量","单位","规格","图层"}]
      }
    }
  },
  "division_count": N
}
```
