# 消防专业工程量计算要点

## 一、系统划分

| 系统 | 典型图纸 | 主要工程量 |
|---|---|---|
| 消火栓系统 | 消防给水平面图、系统图 | 管道、消火栓箱、水泵接合器、消防泵 |
| 自动喷水灭火系统 | 喷淋平面图、系统图 | 喷淋管道、喷头、报警阀、水流指示器 |
| 火灾自动报警系统 | 消防报警平面图、系统图 | 探测器、手报、声光、模块、控制器、线缆 |
| 防烟排烟系统 | 防排烟平面图 | 排烟风机、防火阀、排烟口、挡烟垂壁 |
| 灭火器配置 | 平面图、说明 | 灭火器、灭火器箱 |
| 消防水池/泵房 | 泵房布置图、系统图 | 水池容积、消防泵、稳压设备 |
| 应急照明与疏散 | 应急照明平面图 | 应急灯、疏散指示灯、集中电源 |

## 二、管道与设备

### 消火栓系统
- 管道长度按图层统计（LINE/LWPOLYLINE），管径从图层名或标注提取（DN65、DN80、DN100、DN150）
- 消火栓箱、水泵接合器、消防水泵按块参照计数，单位分别为 套/个/台

### 自动喷水灭火系统
- 喷淋管道长度按管径分层统计，不扣除阀门、管件长度
- 喷头按块参照计数，单位 个；湿式报警阀、水流指示器、末端试水装置按 个/套 计

### 火灾自动报警系统
- 探测器（烟感、温感）、手报、声光报警器、输入/输出模块按块参照计数
- 线缆长度按「点位 × 平均长度 × 1.1」估算，或按桥架/管路长度统计

### 防烟排烟系统
- 排烟风机、送风机按台计；防火阀、排烟口按个计；挡烟垂壁按 m 或 m² 计

## 三、计算口径

- 管道长度不扣除阀门、管件所占长度
- 喷头数量按实际布置计数，不与保护面积反算混用
- 消防水池按有效容积计（m³），消防泵按台计并注明流量/扬程
- 灭火器按「具」计，灭火器箱按「个」计
- 线缆预留长度按项目口径计入（通常 1.1 系数）

## 四、GB 50300 分部分项映射

| 图纸内容 | 分部 | 子分部 | 分项 |
|---|---|---|---|
| 消火栓管道 | 建筑给水排水及供暖 | 室内给水系统 | 室内消火栓系统安装 |
| 喷淋管道 | 建筑给水排水及供暖 | 室内给水系统 | 消防喷淋系统安装 |
| 消防水泵/水池 | 建筑给水排水及供暖 | 室内给水系统 | 给水设备安装 |
| 火灾自动报警 | 智能建筑 | 火灾自动报警系统 | 探测器、控制器、系统调试 |
| 防烟排烟 | 通风与空调 | 防排烟系统 | 风管、部件、风机安装 |

## 五、关键规范

- GB 50016-2014（2018年版）建筑设计防火规范；GB 55037-2022 建筑防火通用规范
- GB 50974-2014 消防给水及消火栓系统技术规范
- GB 50084-2017 自动喷水灭火系统设计规范；GB 50261-2017 自动喷水灭火系统施工及验收规范
- GB 50166-2019 火灾自动报警系统施工及验收标准
- GB 51251-2017 建筑防烟排烟系统技术标准
- GB 50140-2005 建筑灭火器配置设计规范

## 六、消防专业识别关键词

图层/图块/文字：消防、消火栓、喷淋、喷头、火灾报警、烟感、温感、手报、声光、防排烟、防火阀、排烟口、灭火器、消防泵、消防水池、稳压、XHS、XF、SPRINK、FIRE、HYDRANT

## 七、常见问题

- 消火栓与喷淋共用图层，按管径拆分困难
- 火灾报警点位表与平面图数量不一致
- 防排烟常由暖通专业出图，消防汇总时容易漏统
- 消防设备型号、规格未在块属性中标注，无法核对
- 管道穿越防火分区未设防火阀，或防火阀未计入
- 消防水池有效容积与设计说明不一致
- 消防电梯、应急照明分散在电梯/电气专业，汇总时容易漏项

## 八、与 `rules/fire_rules.yaml` 配合

消防专项审图规则独立维护在 `rules/fire_rules.yaml`，与 `default_rules.yaml` 同构。执行方式：

```text
python scripts/cad_rules.py <图名>_CIO.json --rules rules/fire_rules.yaml --enable-cross-discipline --out work --json
```

其中消火栓与结构净距、喷淋与风管碰撞等规则属于跨专业规则，需显式加 `--enable-cross-discipline`；重复图元、零半径图元、文字高度等规则默认启用。规则命中结果写入 `_审图结果.json`，并在 `_审图报告.md` 中按严重级别排序展示。
