# 给排水专业工程量计算要点

## 一、管道工程量

### 提取方式
- 按图层统计管道长度（LINE/LWPOLYLINE/ARC）
- 图层命名通常含管径信息：如 `给水管-DN100`、`污水管-DN150`
- 从图层名或标注文字提取管径

### 管径识别
- DN（公称直径）：DN25、DN50、DN100、DN150
- De（外径）：De32、De110（塑料管）
- Φ（外径）：Φ110（塑料管）

### 单位
- m（米），不扣除阀门、管件长度

### 管道分类
| 系统 | 关键词 | 管材 |
|---|---|---|
| 给水 | 给水、冷水、JS | PP-R、镀锌钢管、钢塑复合管 |
| 排水 | 排水、污水、PS | UPVC、铸铁管 |
| 雨水 | 雨水、YS | UPVC、镀锌钢管 |
| 热水 | 热水、RS | PP-R、铜管 |
| 消火栓 | 消火栓、XHS | 镀锌钢管、无缝钢管 |
| 喷淋 | 喷淋、PL | 镀锌钢管 |

## 二、管件与附件

### 提取方式
- 从图例表识别阀门、地漏、洁具符号
- 按块参照（INSERT）计数
- 从块属性提取型号

### 常见管件
| 类型 | 图例关键词 | 单位 |
|---|---|---|
| 阀门 | 闸阀、蝶阀、止回阀、球阀 | 个 |
| 地漏 | 地漏、FLOOR DRAIN | 个 |
| 水龙头 | 水嘴、龙头 | 个 |
| 水表 | 水表、WATER METER | 个 |
| 水泵 | 水泵、PUMP | 台 |
| 水箱 | 水箱、WATER TANK | 个 |

## 三、卫生器具

### 提取方式
- 从洁具布置图按块计数
- 常见：坐便器、蹲便器、洗手盆、洗脸盆、淋浴器、浴盆、小便器
- 单位：套/个

## 四、消防工程

### 消火栓系统
- 消火栓箱数量（按块计数）
- 消防管道长度（按图层统计）
- 水泵接合器数量

### 自动喷淋系统
- 喷头数量（按块计数）
- 喷淋管道长度（按管径分层统计）
- 湿式报警阀、水流指示器数量
