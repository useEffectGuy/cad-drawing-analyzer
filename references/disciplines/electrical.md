# 电气专业工程量计算要点

## 一、管线工程量

### 提取方式
- 按图层统计管线长度（桥架、导管、电缆）
- 图层命名通常含信息：如 `桥架-200×100`、`电缆-YJV-4×25`

### 桥架
- 规格：宽×高，如 200×100、300×150
- 单位：m（米）
- 分类：强电桥架、弱电桥架、消防桥架

### 导管/线管
- 规格：DN20、DN25、SC20（焊接钢管）、PC20（塑料管）
- 单位：m（米）
- 不扣除接线盒、开关盒长度

### 电缆/电线
- 型号：YJV（交联聚乙烯绝缘）、BV（铜芯聚氯乙烯）、VV、ZR（阻燃）、NH（耐火）
- 规格：YJV-4×25+1×16、BV-3×2.5
- 单位：m（米）
- 需加预留长度：配电箱预留（半周长）、电缆头预留（1.5m）

## 二、设备工程量

### 提取方式
- 按块参照（INSERT）计数
- 从块属性提取型号规格
- 优先级：ATTRIB(tag=MODEL/SPEC/NAME) > 块内文字 > 图层/块名

### 常见设备
| 设备 | 单位 | 说明 |
|---|---|---|
| 配电箱/柜 | 台 | 按型号/回路数 |
| 灯具 | 盏 | 按类型/功率 |
| 插座 | 个 | 按类型（单相/三相） |
| 开关 | 个 | 按极数 |
| 应急照明 | 套 | 含蓄电池 |
| 防雷接地 | 项 | 按系统 |

### 型号规格提取
- 配电箱：型号如 XL-21、PZ30，功率如 30kW
- 灯具：功率如 36W、18W，类型如 LED、荧光
- 电缆：YJV-4×25+1×16（4 根 25mm² + 1 根 16mm²）

## 四、防雷接地

### 提取方式
- 接地极、引下线、均压环、避雷带
- 按长度或根计数
- 接地装置按系统
