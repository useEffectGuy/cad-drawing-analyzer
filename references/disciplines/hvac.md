# 暖通专业工程量计算要点

## 一、风管工程量

### 提取方式
- 按图层统计风管面积（风管通常用双线表示，取中心线长度 × 周长）
- 风管规格标注：如 800×400（宽×高，单位 mm）
- 圆形风管：Φ500

### 面积计算
- 矩形风管面积 = 2 × (宽 + 高) × 长度
- 圆形风管面积 = π × 直径 × 长度
- 单位：m²

| 送风 | 送风、SF |

## 二、风口与部件

### 提取方式
- 按块参照（INSERT）计数
- 从块属性提取规格尺寸
- 常见：散流器、百叶风口、排烟口、防火阀、调节阀

### 常见部件

| 防火阀 | 个 |
| 风量调节阀 | 个 |
| 消声器 | 个 |
| 静压箱 | 个 |

## 三、空调设备

### 提取方式
- 按块参照计数
- 从设备表提取型号参数
- 常见：空调机组(AHU)、风机盘管(FCU)、新风机组、排风机、送风机

### 常见设备
| 设备 | 单位 | 说明 |
|---|---|---|
| 组合式空调机组(AHU) | 台 | 按风量选型 |
| 风机盘管(FCU) | 台 | 按冷量选型 |
| 新风机组 | 台 | 按新风量选型 |
| 排风机/送风机 | 台 | 按风量/风压选型 |
| 冷却塔 | 台 | 按冷却水量 |
| 冷水机组 | 台 | 按制冷量 |

## 四、空调水管

### 提取方式
- 按图层统计管道长度
- 管径从图层名或标注提取
- 分类：冷媒管、冷凝水管、空调供回水管

### 管径识别
- DN（公称直径）：DN25、DN50、DN100
- 冷冻水供回水：通常 DN50~DN300
- 冷凝水管：通常 DN25~DN50

## 五、保温工程量

### 计算口径
- 风管保温面积 = 风管表面积 × 保温厚度（体积）
- 水管保温体积 = π × (管径 + 保温厚) × 保温厚 × 长度
- 单位：m³（体积）或 m²（面积）
