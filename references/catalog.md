# 图纸目录识别规范

## 一、目录版式识别

### 常见目录标题关键词
- 图纸目录、图 纸 目 录、图纸索引、图 纸 索 引、目  录

### 目录表格字段（标准结构）
| 字段 | 说明 | 示例 |
|---|---|---|
| 序号 | 图纸顺序号 | 1, 2, 3 |
| 图号 | 图纸编号 | 建施-01, 结施-03 |
| 图名 | 图纸名称 | 一层平面图 |
| 规格 | 图幅规格 | A1, A2, A3 |
| 备注 | 其他说明 | 初设/施工图 |

### 常见版式变体
1. **标准表格**：5 列（序号/图号/图名/规格/备注）
2. **简化表格**：3 列（序号/图号/图名）
3. **带版本栏**：含版次/日期/设计/审核列
4. **分册目录**：按专业分块，每块有小计

## 二、目录提取流程

```
1. 在整套图纸中搜索目录标题关键词
   ├─ PDF：pdfplumber 逐页提取文字，匹配标题
   └─ DXF：ezdxf 提取文字，匹配标题
2. 定位目录表格区域
   ├─ PDF：标题下方的表格对象
   └─ DXF：标题下方按行列排列的文字
3. 结构化解析
   ├─ 识别表头：含"图号"或首列含图号特征
   ├─ 解析行：按列对齐关系拆分字段
   └─ 提取图号：正则匹配（建施-01 / JS-01）
4. 输出 catalog.json
```

## 三、无目录兜底流程

当整套图纸中找不到图纸目录表格时：

1. 逐张检测图框（默认右下/右上角）
2. 从图签区域提取：图号、图名、比例、版次
3. 按图号排序，补建目录
4. 目录项备注栏标注"图框识别补建"

调用脚本：`detect_titleblock.py <图纸.dxf>`

## 四、目录与逐张识别校验

1. 以 catalog.json 中的图号集合为准
2. 遍历实际文件，文件名（去扩展名）与图号匹配
3. 对不上的文件标"目录外图纸"，单独列出
4. 目录中存在但找不到对应文件的标"缺失图纸"
