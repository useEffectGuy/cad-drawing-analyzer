## 二、图号编号规则

1. **顺序编号**：建施-01, 建施-02, ... 按图纸顺序递增
2. **分册编号**：建施-01~10 为第一册，建施-11~20 为第二册
3. **楼层编号**：建施-0101（1层1号），但较少见
4. **子项编号**：建施-01A, 建施-01B（同号图分 A/B 两张）

## 三、专业判定双重规则

### 规则 1：图号前缀判定（权重高）
- 匹配 `DRAWING_NO_PREFIX_MAP` 中的前缀
- 最长前缀优先匹配（避免"建施"被"建"误匹配）

### 规则 2：图名关键词判定（权重辅）
- 匹配 `DRAWING_NAME_KEYWORDS` 中的关键词
- 取命中数最多的专业

### 置信度判定
| 情况 | 置信度 |
|---|---|
| 图号与图名判定一致 | 高 |
| 仅图号或仅图名命中 | 中 |
| 图号与图名判定不一致 | 中（以图号为准） |
| 均未命中 | 低（标"其他"） |

## 五、常见图号识别正则

```python
# 中文前缀
r"(建施|结施|水施|暖施|电施|设施|装施|消施|智施|总图)[\-]?\d{1,3}"
# 字母前缀
r"[ASPMELF][\-]?\d{1,3}"
# 字母缩写
r"(JS|GS|SS|NS|DS|ZS|XF)[\-]?\d{1,3}"
```
