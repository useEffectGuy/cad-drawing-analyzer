## 一、图纸类型识别
通过图层名、图块名、文字内容综合判断图纸专业与类型。
### 按专业识别关键词
| 专业 | 图层/图块/文字关键词 |
|---|---|
| 建筑 | 墙、门、窗、楼梯、轴线、标高、房间、卫生间、厨房、阳台、WALL、DOOR、WINDOW、AXIS |
| 结构 | 柱、梁、板、基础、钢筋、承台、剪力墙、COLUMN、BEAM、SLAB、REBAR |
| 给排水 | 给水、排水、雨水、污水、消火栓、喷淋、管道、阀门、地漏、WATER、DRAIN、PIPE |
| 电气 | 照明、插座、开关、配电箱、桥架、电缆、防雷、接地、LIGHT、POWER、SOCKET |
| 暖通 | 风管、风口、空调、风机、冷媒、冷凝水、保温、DUCT、AHU、FCU |
| 总图 | 红线、道路、绿化、坐标、场地、竖向、REDLINE、ROAD |
| 装饰 | 地面、墙面、天花、踢脚、造型、饰面、FLOOR、CEILING |
### 按图纸类型识别
- **平面图**：含"平面图"文字，图块数量多，有房间名称标注
- **立面图**：含"立面图"，标高标注多，图形呈竖向分布
- **剖面图**：含"剖面图"，有剖切符号，标高密集
- **大样图/节点图**：含"大样""节点""详图"，图形局部放大，标注密集
- **系统图**：含"系统图"，管线连接关系为主
- **总平面图**：含"总平面"，有坐标标注、指北针
## 二、图层分析要点
### 图层命名规范检查
常见规范要求（视企业标准而定）：
- 图层名应体现专业和构件类型，避免 `图层1`、`Layer1` 这类无意义命名
- 实体不应放在默认图层 `0` 上（除块定义内部）
- 图层颜色应区分明显，便于识图
- 图层线型应与构件性质匹配（如轴线用点划线 CENTER）
### 图层实体分布解读
- **某图层实体数异常多**：可能是该专业主要构件，也可能是误操作导致实体堆积
- **图层实体数为 0**：未使用图层，建议清理以减小文件体积
- **图层被关闭/冻结**：可能是设计过程中的临时状态，交付前应检查
### 常见问题
| 问题 | 判断依据 | 影响 |
|---|---|---|
| 实体在 0 图层 | `layer == "0"` 的实体数 > 0 | 图层管理混乱，难以控制显示 |
| 空图层过多 | 实体数为 0 的图层占比高 | 文件冗余 |
| 图层命名混乱 | 存在 `图层1`、`新建图层` 等 | 不符合制图规范 |
| 图层颜色重复 | 多图层使用同一颜色 | 识图困难 |
## 三、图块与工程量统计
### 图块统计的价值
图块数量统计 = 构件/设备数量统计。这是 CAD 图纸分析最实用的功能：
- 门窗统计 → 门窗表
- 灯具统计 → 照明设备清单
- 洁具统计 → 卫浴设备清单
- 设备统计 → 设备材料表
- 插座开关统计 → 电气点位表
### 带属性图块的信息提取
属性（ATTRIB）里通常存着关键信息：
```
配电箱图块属性：
  编号 = AL1
  型号 = XL-21
  功率 = 30kW
  回路数 = 8
门图块属性：
  编号 = M0921
  类型 = 单扇平开门
  宽度 = 900
  高度 = 2100
  防火等级 = 乙级
```
提取这些属性可以自动生成设备表/门窗表。
### 嵌套块处理
图块可能嵌套（一个图块内部包含另一个图块）。统计时要考虑：
- 是否需要展开嵌套块统计内部图块
- 避免循环引用导致无限递归（设置深度上限）
- 用 `insert.virtual_entities()` 展开
### 动态块
动态块（Dynamic Block）有多个可见性状态，不同状态下图形不同。ezdxf 对动态块支持有限，统计时按块名计数，不区分可见性状态。
## 四、文字信息分析
### 文字提取的应用
- **房间名称** → 房间清单、面积核对
- **材料说明** → 材料表
- **技术参数** → 设计参数提取
- **图号标题** → 图纸目录
- **标高数值** → 竖向设计数据
### 词频分析
按词频统计能快速抓住图纸主题。高频词往往对应图纸的核心内容：
- 高频出现"卫生间"→ 可能是住宅/公建平面图
- 高频出现"标高"→ 可能是立面图/剖面图
- 高频出现"DN"（管径）→ 给排水图纸
- 高频出现"BV"（电线型号）→ 电气图纸
### 文字定位
文字坐标可用于定位。结合图纸范围，能判断文字在图纸上的位置（左上/右上/中部），有助于判断是标题栏、图例还是图面标注。
## 五、规范性检查清单
### 几何层面
- [ ] 是否存在零长度直线（起终点重合）
- [ ] 是否存在零半径圆
- [ ] 是否存在重复实体（同位置同类型）
- [ ] 是否存在极短线段（< 0.1 单位）
### 图层层面
- [ ] 是否有实体在 0 图层
- [ ] 是否有未使用的空图层
- [ ] 图层命名是否规范
- [ ] 图层颜色线型是否合理
### 文字层面
- [ ] 文字高度是否过小（< 0.5 单位，打印不可读）
- [ ] 是否存在乱码文字
- [ ] 标注文字是否与测量值一致
### 图块层面
- [ ] 是否存在未使用的块定义
- [ ] 带属性图块的属性是否完整（无空值）
- [ ] 是否存在同名不同内容的块
## 六、专业判断经验
### 图纸完整度判断
- 有图框（图框通常是大矩形 + 标题栏文字）→ 正式出图
- 无图框 → 可能是设计过程稿
- 有图号、日期、设计人 → 正式图纸
- 有"施工图""竣工图"文字 → 对应阶段
### 比例推断
从图框尺寸推断比例。常见图框：
| 图幅 | 尺寸(mm) | 常用比例 |
|---|---|---|
| A0 | 1189 × 841 | 1:100, 1:50 |
| A1 | 841 × 594 | 1:100, 1:50 |
| A2 | 594 × 420 | 1:100, 1:50 |
| A3 | 420 × 297 | 1:100, 1:50, 1:30 |
| A4 | 297 × 210 | 1:50, 1:30, 1:20 |
若图纸范围是 42000 × 29700 单位（假设单位 mm），对应 A3 图框 420×297mm，则比例为 1:100。
### 数据合理性校验
- 门数量与建筑面积：住宅约每 100㎡ 有 3-5 樘门
- 窗地比：一般房间窗地比 1:6 ~ 1:4
- 灯具密度：办公约每 8-12㎡ 一盏灯
- 插座密度：住宅每房间 2-4 个
这些经验值可用于校验统计结果是否合理，发现异常时提示用户复核。
### 报告撰写建议
不要只罗列数据，要给出解读：
**差的写法**：
> 图层 WALL 有 1523 个实体。
**好的写法**：
> 图层 WALL 有 1523 个实体，占全图实体的 38%，是图纸主体。该图层实体以 LWPOLYLINE 为主（1420 个），符合墙体用多段线绘制的常规做法。
**差的写法**：
> 图块统计：门 12 个，窗 24 个。
**好的写法**：
> 图块统计显示门 12 樘、窗 24 樘，门窗比 1:2，符合住宅建筑常规配置。若按每户 3 樘门估算，本图约含 4 户，建议与建筑平面图核对户数。
